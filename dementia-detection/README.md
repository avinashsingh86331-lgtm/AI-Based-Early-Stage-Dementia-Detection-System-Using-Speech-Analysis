# 📌 About The Project

Dementia is a progressive neurological disorder that affects memory, thinking ability, and daily life activities. Early diagnosis is extremely important because timely treatment can slow disease progression and improve patient care.

This project uses:

✅ Speech-to-Text Technology  
✅ Machine Learning Algorithms  
✅ Cognitive Speech Analysis  
✅ AI Prediction Models  

to predict dementia risk efficiently and accurately.

# 🚀 Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/dementia-detection-system.git
```

## 2️⃣ Open Project Folder

```bash
cd dementia-detection-system
```

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

## 4️⃣ Run Backend Server

```bash
python app.py
```

## 5️⃣ Open Frontend

Open `index.html` in your browser 🌐
